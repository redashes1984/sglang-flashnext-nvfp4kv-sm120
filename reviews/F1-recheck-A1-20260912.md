### 1. remap_topk_ids 钳制（patches/expert_cold_pool.py :300-309）

修复后代码：

```python
safe = topk_ids.clamp(min=0).long()
ok = (safe < tbl.numel()) & (topk_ids >= 0)
mapped = tbl[safe.clamp(max=tbl.numel() - 1)].to(topk_ids.dtype)
return torch.where(ok, mapped, topk_ids)
```

- 越界 gather 根除：`safe.clamp(max=numel-1)` 保证索引行恒在表内，`ok` 掩码把融合共享列（id≥numel）原样透传——正是 R1 报告药方，逐字符一致。
- 语义保留：`-1` padding 走 `topk_ids >= 0` 排除、透传不变（旧行为不回退）。
- 双路对称：与 packed 路径 `:322` 的 `clamp(max=tbl.numel()-1)` 现在同一模式，审计"两路不对称"批评消除。
- 原 🟢-4（`.to(topk_ids.dtype)` 截断风险）：本 commit 未触碰。维持 🟢——tbl 值域为 [0,width) 的 int64 行号，int32 下 width=512 远不触截断边界，理论项。
